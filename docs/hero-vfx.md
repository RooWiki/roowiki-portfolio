# Hero VFX

The hero uses an AI-generated, compressed 1536 × 1024 WebP texture (190 KiB), animated with a single WebGL quad. Sinusoidal UV displacement and heat-masked brightness modulation provide continuous flame motion. This is a stylized animated texture, not a simulated explosion lifecycle or fluid volume. The legacy Three.js effects remain available in source, but are no longer imported by the hero or bundled into the application.

The renderer caps width at 1100 physical pixels and rendering at 30 Hz. The artwork is fixed behind the page content, so it remains visible and animated while scrolling. IntersectionObserver still checks visibility of the artwork itself, and page visibility stops animation in hidden tabs. On mobile the background dims after the introduction leaves the viewport to preserve text readability. Reduced motion skips WebGL; a normal image also provides the fallback when WebGL is unavailable or its context is lost. Context loss keeps the image visible until remount. GPU resources and observers are released on cleanup.

The presentation layout changes to a left-to-right plume and the same sans-serif font and white/gray design tokens as the content sections. Existing content sections are unchanged. The introduction inherits the site font and adds no font downloads.

Validation: npm run build and npm run lint pass. Chromium checks at 1600 × 900 and 390 × 844 produced no page errors or mobile horizontal overflow. Draw-call instrumentation measured 22 draws in one second under headless software rendering, 22 draws per second after scrolling beyond the introduction and zero with reduced motion. The artwork stays fixed at 52px below the viewport top. This validates scheduling, not a hardware FPS benchmark or measured speedup over production. Production output: 211.91 kB JS (66.43 kB gzip).
